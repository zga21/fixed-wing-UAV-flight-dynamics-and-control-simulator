## Background

Near a trim point, the aircraft's complicated nonlinear behaviour is very well
approximated by a simple linear model: a matrix `A` describing how the aircraft
responds to being nudged, and a matrix `B` describing how it responds to control
inputs. Simple linear models are what classical control design tools work with.

You get these matrices by poking the aircraft. Perturb one state by a tiny
amount, see how the derivatives change, divide. Do that for all 13 states and 4
inputs and you have the matrices.

Central differences (poke both ways and average) are used rather than forward
differences because they are second-order accurate for the same conceptual cost,
and the accuracy matters — these matrices feed the mode analysis that validates
your entire model.

    Numerical Jacobians by central differences.

        A[i,j] = (f_i(x* + eps*e_j, u*) - f_i(x* - eps*e_j, u*)) / (2*eps)

Step size: `1e-6` is a reasonable default, but verify it. Too large and you
capture nonlinearity; too small and floating-point cancellation dominates. Sweep
`eps` from `1e-3` to `1e-9` and confirm there is a plateau where `A` is stable to
several digits. Use a value in the middle of that plateau.

## Acceptance criteria

- [ ] `A` and `B` have the right shapes and no NaN
- [ ] **Step-size plateau verified** and documented in a test
- [ ] **Decoupling:** longitudinal-to-lateral coupling blocks are below `1e-8`
      in a symmetric trim. Non-zero values mean a modelling asymmetry — go find it
- [ ] Cross-check at least three entries against hand-derived analytic
      expressions, e.g. `dwdot/dq ≈ u_0` and the `Z_alpha` term. Write the
      derivation in the test docstring
- [ ] Independent check: reproduce `A` with `scipy.optimize.approx_fprime` and
      confirm agreement to 1e-6
- [ ] Linearising at two nearby trim points gives similar `A` (continuity)

## Notes

If you have MATLAB or Simulink available, this is the single best place to use
it: build the same linear model there and compare eigenvalues. An independent
implementation agreeing with yours is much stronger evidence than any number of
self-consistent tests, and it is a legitimate, cheap use of a second tool without
maintaining a second full simulator.
