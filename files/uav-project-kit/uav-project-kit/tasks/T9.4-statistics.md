## Background

This task turns 20,000 rows into the sentence the whole project exists to
support. Three things must be right.

**The confidence interval.** Use Wilson, not the normal approximation. When the
success rate is near 1 — which it will be — the normal approximation gives
intervals that extend above 100%, which is embarrassing in a report.

**The comparison test.** Use McNemar, because the cases are *paired*: the same
seed gave both controllers the same aircraft and the same wind. An unpaired test
discards that pairing and most of your statistical power with it.

**Distributions, not averages.** The median tells you about a typical flight. The
95th and 99th percentiles tell you about the flights that matter. Report both.

def mcnemar_test(results_a: pd.Series, results_b: pd.Series) -> TestResult:
    """
    Paired comparison of two controllers on the SAME cases.

        b = cases where A succeeded and B failed
        c = cases where A failed and B succeeded
        chi2 = (|b - c| - 1)^2 / (b + c)        # continuity-corrected

    Raises if the two series are not aligned by seed -- silently comparing
    unpaired data is the failure mode this guard exists to prevent.
    """
