## Background

Two jobs. First, answer RQ3: can optimisation improve performance without
overfitting? Second — and this is the one that determines whether Phase 6's
comparison survives review — tune **both** controllers with the same optimiser
and the same budget.

If NDI gets 2000 evaluations and the PID gets whatever you tuned by hand in an
afternoon, the comparison measures your patience, not the control architecture.
Running both through the same procedure removes that objection completely, and it
costs one extra overnight run.

```python
    """
        Delta = (J_val - J_train) / J_train
    Delta > 0.2 means the tuner has fitted the training scenarios rather than

    """
```

If `Delta > 0.2`, the remedies in order of preference: enlarge the training set
(most effective, and cheapest to justify); add the `lambda*||k||^2`
regularisation term from T7.2; reduce the number of free gains by fixing the ones
the optimiser barely moves.

## Acceptance criteria

- [ ] Both controllers tuned with identical budget and settings
- [ ] `Delta < 0.2` for both — if not, remediate and re-run, documenting what
      you changed
- [ ] Tuned versus untuned improvement quoted for both controllers separately.
      This is the direct answer to RQ3
- [ ] Convergence plots for both, saved to `docs/figures/tuning/`
- [ ] The overfitting curve (train and validation `J` versus generation) plotted
      for both — this figure *is* the RQ3 answer and belongs in the report
- [ ] Tuned gains committed to `config/gains_tuned_v1.yaml` with provenance
- [ ] The Phase 6 comparison re-run with both tuned; result recorded whichever
      way it goes
- [ ] `docs/tuning_results.md` states plainly which gains moved most, and what
      that reveals about which loop dominates performance

## Notes

Look at *which* gains the optimiser changed. If it drove the derivative gains to
zero, that tells you sensor noise is dominating. If it pushed the rate loop much
harder, the inner loop was under-tuned by hand. These observations are worth a
paragraph each and they show you understood the result rather than just ran the
tool.

And if the tuned PID now matches or beats the tuned NDI — report it plainly.
That is a real finding about this aircraft and this envelope, and a study that
reports it honestly is more credible than one where the advanced method always
wins.
