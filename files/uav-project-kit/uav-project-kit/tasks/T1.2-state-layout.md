## Background

The aircraft state is a 13-element array. Every module will need to pull the
velocity out of it, or the quaternion, or the angular rates. If each module
writes `x[3:6]` inline, then the day you change the layout you have to find
every one of those slices, and you will miss one.

So the layout is defined once, here, as named constants, and nothing else in the
codebase ever writes a bare index.

This is a small task with an outsized effect on how debuggable the rest of the
project is.

## What to implement

```python
"""State vector layout. The single source of truth for indexing.

    x = [p_N, p_E, p_D, u, v, w, q0, q1, q2, q3, p, q, r]

Note the naming collision: `q` is pitch rate (index 11) AND the quaternion.
In this codebase the quaternion is always `quat`; bare `q` is always pitch rate.
"""

N_STATES = 13

IDX_POS   = slice(0, 3)    # p_N, p_E, p_D   NED frame, m
IDX_VEL   = slice(3, 6)    # u, v, w         body frame, m/s
IDX_QUAT  = slice(6, 10)   # q0..q3          body-to-NED, unit norm
IDX_OMEGA = slice(10, 13)  # p, q, r         body frame, rad/s

@dataclass(frozen=True)
class State:
    """Readable view of a state vector. Convert at boundaries, not in loops."""
    pos_n: np.ndarray     # (3,)
    vel_b: np.ndarray     # (3,)
    quat: np.ndarray      # (4,)
    omega_b: np.ndarray   # (3,)

    @classmethod
    def from_array(cls, x: np.ndarray) -> "State": ...
    def to_array(self) -> np.ndarray: ...

    @property
    def altitude(self) -> float:
        """h = -p_D. THE ONLY PLACE THIS CONVERSION HAPPENS."""
        return -self.pos_n[2]

    @property
    def euler(self) -> np.ndarray:
        """(3,) [phi, theta, psi] rad. For plotting and logging only."""

def make_state(pos_n, vel_b, quat, omega_b) -> np.ndarray:
    """Assemble a (13,) array with validation."""

def initial_state(V: float, alpha: float = 0.0, h: float = 100.0,
                  psi: float = 0.0) -> np.ndarray:
    """Convenience constructor for tests and scenarios."""
```

Keep `State` out of the integration hot loop — inside RK4 you work on the raw
`(13,)` array for speed. `State` is for readable code at the boundaries: tests,
logging, controllers, plots.

## Acceptance criteria

- [ ] `State.from_array(x).to_array()` returns `x` exactly for random arrays
- [ ] `altitude` returns `+100.0` when `p_D = -100.0` — assert this explicitly,
      it is the sign convention that causes the most bugs in the project
- [ ] `make_state` raises if the quaternion is not unit norm to 1e-6
- [ ] A grep for `x[3:6]`, `x[6:10]`, `x[10:13]` anywhere outside `state.py`
      returns nothing. Consider adding this as a test that scans the source
      tree — it is three lines and it enforces the rule permanently

The self-scanning test is worth writing:

```python
def test_no_raw_state_indexing():
    """No module outside state.py may index the state vector directly."""
    pattern = re.compile(r"x\[\s*\d+\s*:\s*\d+\s*\]")
    for path in Path("src/uav_sim").rglob("*.py"):
        if path.name == "state.py":
            continue
        assert not pattern.search(path.read_text()), f"raw indexing in {path}"
```
