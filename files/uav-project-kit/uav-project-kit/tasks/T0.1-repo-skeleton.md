## Background

Nothing in this project is worth building until there is a place to put it and
a single command that tells you whether it still works. Reproducibility is part
of the engineering result, not an administrative afterthought — a Monte Carlo
success rate that cannot be traced back to a specific commit is not evidence.

This task creates the folder structure, the packaging metadata, the test runner
and the `Makefile` that every later task calls. It contains no physics.

## What to implement

**`src/uav_sim/constants.py`** — this is the only file in `src/` allowed to
contain bare numeric literals:

```python
"""Physical constants. Nothing else in src/ may contain magic numbers."""

G0: float = 9.80665           # standard gravity, m/s^2
RHO_SL: float = 1.225         # sea-level air density, kg/m^3
T_SL: float = 288.15          # sea-level temperature, K
P_SL: float = 101325.0        # sea-level pressure, Pa
LAPSE_RATE: float = 0.0065    # ISA troposphere lapse rate, K/m
R_AIR: float = 287.053        # specific gas constant for dry air, J/(kg K)
GAMMA_AIR: float = 1.4        # ratio of specific heats
```

**`tests/conftest.py`** — register the markers the gate tests will use:

```python
def pytest_configure(config):
    config.addinivalue_line("markers", "gate: phase exit criteria")
    config.addinivalue_line("markers", "slow: long-running campaign tests")
```

**`Makefile`** — these targets are referenced by every later task:

```make
.PHONY: test test-fast gate lint format types reproduce

test:       ; pytest -v
test-fast:  ; pytest -v -m "not gate and not slow"
gate:       ; pytest -v -m gate tests/gates/test_phase_$(PHASE).py
lint:       ; ruff check src tests && black --check src tests
format:     ; black src tests && ruff check --fix src tests
types:      ; mypy src
reproduce:  ; python scripts/reproduce_all.py
```

**`.gitignore`** must include `results/`, `figures/`, `.venv/`, `__pycache__/`,
`*.egg-info/`, `.pytest_cache/`.

## Acceptance criteria

- [ ] `pip install -e ".[dev]"` succeeds in a clean virtual environment
- [ ] `make test` runs and passes (zero tests collected is fine at this stage)
- [ ] `make lint` passes
- [ ] `import uav_sim; uav_sim.__version__` works
- [ ] `git status` is clean after a full `make test` run — nothing generated is
      tracked
- [ ] First commit made, `main` branch exists

## Notes

Use the `src/` layout rather than a flat package. It forces you to install the
package properly, which means the tests import the same code the scripts do —
this prevents a whole class of "works on my machine" problems in Phase 9 when
multiprocessing workers import the package independently.
