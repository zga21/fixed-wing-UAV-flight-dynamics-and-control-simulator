## Background

Nonlinear dynamic inversion needs the aircraft's dynamics written in a
particular shape: everything the aircraft does on its own, plus a matrix
multiplying the control inputs.

```
omega_dot = f(x) + g(x) * delta
```

`f(x)` is what happens with the surfaces neutral. `g(x)` is how much each surface
changes things — the control effectiveness. Once you have both, the inversion in
T6.2 is one line.

The important design decision here is that this is the controller's **internal
model**, which is deliberately not the same object as the simulator's plant. It
is an approximation the controller carries around, and the gap between it and the
true plant is exactly what Phase 6 is studying. Keeping them as separate objects
in the code makes that gap explicit and lets you corrupt the controller's model
independently in T6.5.

## What to implement

```python
class ControlAffineModel:
    """
    The controller's INTERNAL model of the aircraft. Deliberately distinct
    from the plant: the mismatch between them is the object of study.
    """
    def __init__(self, cfg: AircraftConfig, aero_derivs: AeroDerivatives): ...

    def f(self, x_hat: np.ndarray, air: AirData) -> np.ndarray:
        """
        Control-independent angular acceleration:
            f = I^-1 (M_0(x) - omega x (I omega))
        where M_0 excludes all control-surface contributions.
        """

    def g(self, air: AirData) -> np.ndarray:
        """
        Control effectiveness, (3,3):
            g = I^-1 * q_bar * S * G
            G = [[b*C_l_da, 0, b*C_l_dr],
                 [0, c*C_m_de, 0],
                 [b*C_n_da, 0, b*C_n_dr]]

        Scales with q_bar, so it approaches singular as airspeed drops.
        Guarded in T6.2.
        """

    def perturb(self, **factors) -> "ControlAffineModel":
        """
        Return a copy with derivatives scaled -- e.g. perturb(C_m_alpha=1.3).
        Used by T6.5 to corrupt the controller's model on purpose.
        """
```

## Acceptance criteria

- [ ] `f(x) + g(x) @ delta` reproduces the plant's `omega_dot` to within 1e-6
      when the controller model and plant model use identical derivatives
- [ ] `g` is invertible across the envelope above `V = 12` m/s
- [ ] `cond(g)` is computed and logged; it rises sharply at low airspeed
- [ ] `g` scales linearly with `q_bar` — assert by doubling dynamic pressure
- [ ] `perturb()` returns an independent copy; the original is unmodified
- [ ] The controller model never imports from `plant.py`

## Notes

That last criterion is worth enforcing with a test. If the controller can reach
into the plant, someone will eventually use the plant's true derivatives inside
the controller, the model mismatch will vanish, and NDI will look miraculous for
entirely fake reasons. Keeping the two objects separate is what makes the
Phase 6 result honest.
