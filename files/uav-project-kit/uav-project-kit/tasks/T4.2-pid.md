## Background

The PID controller is the workhorse of control engineering: look at the error,
push proportionally to it, push more the longer it persists, and damp based on
how fast it is changing.

Two details separate a textbook PID from one that survives contact with a real
aircraft.

**Derivative kick.** If you differentiate the *error*, a step change in the
command produces an instantaneous infinite derivative and a violent control
spike. Differentiating the *measurement* instead gives identical disturbance
rejection without the spike.

**Integral windup.** When the actuator is saturated, the integrator keeps
accumulating error it cannot act on. When the aircraft finally responds, that
accumulated integral drives a massive overshoot. This does not show up in Phase 4
where actuators are ideal — it appears in Phase 5 and looks like the controller
has suddenly become terrible. Build the fix now.

## What to implement

```python
class PID:
    """
    Discrete PID with derivative-on-measurement and back-calculation
    anti-windup.

        u = Kp*e + I + D
        I += Ki*Ts*e + (Ts/Tt)*(sat(u) - u)          # back-calculation
        D  = (Kd/(Kd + N*Ts))*D_prev
             - (Kd*N/(Kd + N*Ts))*(y - y_prev)       # on measurement
    """
    def __init__(self, kp, ki, kd, N=20.0,
                 limits=(-np.inf, np.inf), Tt=None, name=""): ...
    def update(self, setpoint: float, measurement: float, dt: float) -> float: ...
    def reset(self) -> None: ...
```

`N` is the derivative filter coefficient; without it, `Kd` amplifies the sensor
noise you add in Phase 5 into unusable control chatter. `Tt` is the tracking time
constant for back-calculation, typically `sqrt(Ti*Td)` or simply `Ti`.

## Acceptance criteria

- [ ] Pure P on a first-order plant gives the analytically expected steady-state
      error
- [ ] Adding I drives steady-state error to zero
- [ ] **No derivative kick.** A step setpoint change produces no spike in `u`.
      Compare against a deliberately wrong derivative-on-error version and assert
      the peak is smaller by an order of magnitude
- [ ] **Anti-windup works.** Saturate the output for 10 s, then release. Overshoot
      with back-calculation must be dramatically smaller than without. Test both
      paths in the same test so the comparison is explicit
- [ ] `reset()` zeroes the integrator and derivative history
- [ ] `dt = 0` does not divide by zero
- [ ] Deterministic: same inputs, same outputs, bit for bit
