## Background

To learn a correction, you need something to be corrected *against*. This task
creates the higher-fidelity reference and extracts the differences.

The honest framing matters here. You are not learning "the truth" — you are
learning the gap between a simplified model and a more detailed one, both of
which you wrote. That is still a genuine and useful experiment: it demonstrates
the method, and it quantifies uncertainty in a setting where you know the right
answer, which is exactly how you would validate the technique before applying it
to real flight data.

Say that plainly in the report. A reviewer will ask, and having pre-empted it
reads much better than being caught by it.

      - alpha-beta cross-coupling in the lateral derivatives

Hold out a test set by **region**, not at random: train on `|alpha| < 8°` and
test on `8° < |alpha| < 14°`. Random splitting makes extrapolation look easy
because a nearby training point is always available, and extrapolation behaviour
is precisely what T8.3 needs to measure.

## Acceptance criteria

- [ ] `TableAeroModel` satisfies the `AeroModel` protocol and drops into the
      plant with no other changes
- [ ] Both models agree closely at small alpha and diverge at large alpha —
      plot and confirm
- [ ] Dataset has ≥5000 samples with even envelope coverage (plot the sample
      distribution)
- [ ] Residuals are non-trivial: standard deviation at least 5% of the
      coefficient magnitude, otherwise there is nothing to learn
- [ ] Region-based train/test split, not random
- [ ] Dataset committed or regenerable from a recorded seed
- [ ] The plant flies stably with `TableAeroModel` substituted

## Notes

Keep the reference model physically plausible. If you make it arbitrarily weird,
the GP will learn something arbitrary and the exercise proves nothing. The point
is that the residual has structure a GP can find — smooth, alpha-dependent,
concentrated near the envelope edge. That is what real modelling error looks like.
