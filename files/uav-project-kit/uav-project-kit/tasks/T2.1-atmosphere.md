## Background

Air gets thinner with altitude, and every aerodynamic force is proportional to
air density. So before you can compute lift you need to know how dense the air
is where the aircraft currently is.

The International Standard Atmosphere is a simple agreed model of that. Below
11 km it is a single formula. This is one of the easiest tasks in the project,
but it feeds every force calculation, so it is worth getting exactly right.

Density variation also becomes one of your Phase 9 uncertainty parameters —
real air is not standard air, and a controller tuned at sea-level density may
behave differently at 1000 m on a hot day.

## What to implement

```python
@dataclass(frozen=True)
class AtmosphereState:
    rho: float          # density, kg/m^3
    temperature: float  # K
    pressure: float     # Pa
    sound_speed: float  # m/s

def isa(altitude_m: float, delta_isa: float = 0.0) -> AtmosphereState:
    """
    ISA troposphere model, valid 0 to 11000 m.

        T = T_SL - LAPSE_RATE * h + delta_isa
        p = P_SL * (T / T_SL) ** (G0 / (LAPSE_RATE * R_AIR))
        rho = p / (R_AIR * T)
        a = sqrt(GAMMA_AIR * R_AIR * T)

    Args:
        altitude_m: geometric altitude, m. Clamped to >= 0.
        delta_isa:  temperature offset from standard, K. Used in Phase 9 to
                    sample "hot day" and "cold day" conditions.

    Returns: AtmosphereState
    """

def density_ratio(altitude_m: float) -> float:
    """rho(h) / rho_sea_level. Convenience for scaling."""
```

Clamp altitude at zero rather than raising — in Phase 9 an aircraft that has
crashed will briefly report negative altitude before the run terminates, and you
do not want that path to raise inside a worker process.

## Acceptance criteria

- [ ] `isa(0).rho == pytest.approx(1.225, rel=1e-4)`
- [ ] `isa(0).temperature == pytest.approx(288.15, rel=1e-6)`
- [ ] `isa(0).pressure == pytest.approx(101325.0, rel=1e-4)`
- [ ] `isa(0).sound_speed == pytest.approx(340.3, rel=1e-3)`
- [ ] Density decreases monotonically over `h ∈ [0, 11000]` — test with a sweep
- [ ] `isa(1000).rho == pytest.approx(1.112, rel=1e-3)` (a published value —
      cite the source in the test docstring)
- [ ] `delta_isa=+15` (hot day) reduces density relative to standard
- [ ] Negative altitude is clamped, not an error

## Notes

Do not model above 11 km. The stratosphere needs a different formula, your
envelope tops out at 1000 m, and unused code is code that can be wrong without
anyone noticing. If you ever need it, add it then, with its own test.
