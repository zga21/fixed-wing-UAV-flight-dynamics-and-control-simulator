## Background

Every figure in the report is generated by a committed script that reads the
exported results. No figure is ever assembled by hand, cropped from a screenshot,
or tweaked in an image editor.

This is not neatness for its own sake. It means that when you fix a bug and re-run
the campaign, every figure updates automatically and none of them silently keeps
showing old data. It is also what makes `make reproduce` meaningful.

## Acceptance criteria

- [ ] Every figure has its own script, named after the figure
- [ ] Every script reads only from `results/export/` — never from Parquet, never
      from hard-coded numbers
- [ ] `scripts/reproduce_all.py` regenerates all twenty from scratch
- [ ] Consistent style: same fonts, colours, sizes throughout
- [ ] Every axis labelled with units; every figure has a standalone caption
- [ ] Colour-blind safe palette, and no figure relies on colour alone to
      distinguish series — use line style as well
- [ ] Vector output (PDF or SVG) for the report, PNG for the website
- [ ] A test asserts that no figure script contains a numeric literal that
      should have come from the data

## Notes

The most valuable figures are the verification ones, 1–4. Almost every comparable
project shows a controller tracking a reference; very few show evidence that the
underlying model is correct. Lead with those, both in the report and on the site.

Figure 11 (NDI speed independence) and figure 15 (the confidence map) are the two
that will do the most work in a portfolio context. Make them excellent.
