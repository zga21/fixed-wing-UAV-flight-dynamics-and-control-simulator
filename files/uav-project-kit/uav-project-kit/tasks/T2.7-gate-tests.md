## Background

Phase 1's gate checked conservation laws. This gate checks **signs and
monotonicity** — the properties that make the difference between an aircraft and
an object that merely obeys Newton's laws.

Every one of these tests corresponds to a real failure mode. A positive
`C_m_alpha` gives you an aircraft that diverges in pitch, and the symptom looks
exactly like a badly tuned controller, which is where you will waste the week.

## What to implement

```python
@pytest.mark.gate
def test_lift_increases_with_alpha(aero_model, geom):
    """Catches: sign error in C_L_alpha, or alpha computed with wrong sign."""
    alphas = np.deg2rad(np.linspace(-5, 10, 50))
    C_L = [aero_model.coefficients(...).C_L for a in alphas]
    assert np.all(np.diff(C_L) > 0)

@pytest.mark.gate
def test_static_pitch_stability(derivs):
    """
    C_m_alpha must be negative.

    Catches: an aircraft that pitches up harder the more it pitches up, i.e.
    divergent. The symptom in Phase 4 is a controller that 'cannot be tuned',
    and you will blame the controller.
    """
    assert derivs.C_m_alpha < 0

@pytest.mark.gate
def test_damping_derivatives_negative(derivs):
    """
    C_m_q, C_l_p, C_n_r all negative: damping opposes motion.
    A positive damping derivative means the simulator creates energy.
    """
    assert derivs.C_m_q < 0
    assert derivs.C_l_p < 0
    assert derivs.C_n_r < 0

@pytest.mark.gate
def test_lateral_symmetry_exact(aero_model, geom):
    """
    Symmetric aircraft, symmetric flight -> EXACTLY zero lateral force
    and moments. Not approximately. Catches index swaps and stray coupling.
    """
    c = aero_model.coefficients(air=AirData(V=25, alpha=0.05, beta=0.0, ...),
                                omega_b=np.array([0.0, 0.1, 0.0]),
                                controls=np.array([0.0, -0.05, 0.0, 0.5]),
                                geom=geom)
    assert c.C_Y == 0.0
    assert c.C_l == 0.0
    assert c.C_n == 0.0

@pytest.mark.gate
def test_control_signs_match_convention(aero_model, geom):
    """Positive elevator -> nose down. Positive aileron -> right roll.
    Positive rudder -> nose right. Per docs/conventions.md section 4."""

@pytest.mark.gate
def test_open_loop_flight_is_plausible(plant, cfg):
    """
    60 s of hands-off flight from near-trim:
      - no NaN
      - altitude within 100 m of start
      - airspeed within [10, 50] m/s
      - a visible damped pitch oscillation after a small doublet
    """

@pytest.mark.gate
def test_atmosphere_reference_values():
    """rho(0)=1.225, monotonically decreasing to 11 km."""
```
