# Phase 3 Validation Notes

Phase 3 adds the steady-flight trim solver, numerical linearisation, and mode
identification used by the controller phases. The validation gate trims the
frozen v1 aircraft, flies a held trim for 60 seconds, checks symmetric
longitudinal/lateral decoupling, identifies all five textbook fixed-wing modes,
and compares small-signal and large-signal elevator doublets against the full
nonlinear plant.

The exact project-kit descent grid requests `gamma = -5 deg` at `V = 18 m/s`.
With the frozen v1 Phase 2 model, propulsion is thrust-only and the drag model
has no windmilling or explicit drag device. Low-speed steep descents can require
less than idle thrust or additional drag, so the gate records that corner as
unreachable instead of changing benchmark parameters to rescue the result. The
committed validation grid uses the reachable envelope
`V = {18, 25, 35} m/s` and `gamma = {-2, 0, +5} deg`, with residuals below
`1e-10`.
