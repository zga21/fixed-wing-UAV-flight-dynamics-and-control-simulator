# Phase 5 — Finish & Verify Runbook

Steps to complete Phase 5 (sensors, actuators, wind, EKF, degradation study) and
confirm the gate is green. Run each block from the repo root (`D:\DEFENSE_PROJ`)
in your own Python environment (the one with the project deps installed).

Two items were outstanding when this runbook was written:
1. The EKF was not statistically consistent (NEES gate) — **fixed in code**.
2. The degradation table (`docs/degradation_table.md`, the RQ1 deliverable) had
   not been generated yet — **step 1 below generates it**.

---

## 1. Generate the degradation table (RQ1 deliverable)

```bash
python scripts/degradation_study.py --seeds 6 --workers 6
```

- Produces `docs/degradation_table.md`, `docs/degradation_record.json`, and
  `docs/figures/degradation/mechanism_contributions.png`.
- Runtime: roughly 10–20 minutes. It is **resumable** — completed cases persist
  in `results/phase5/degradation_cases.jsonl`, so re-running continues rather
  than restarting.
- 6 seeds is enough for Phase 5's directional question (does the baseline
  degrade, and which mechanism dominates). Extend later with `--seeds 20` for a
  report-grade table if desired.

Watch progress from a second terminal (counts up toward 63 cases):

```bash
python -c "print(sum(1 for _ in open('results/phase5/degradation_cases.jsonl')))"
```

If a run ever appears stuck, check for leftover worker processes
(`Get-Process python`) and end any stray ones before retrying — orphaned
`ProcessPoolExecutor` workers are the usual cause of a slow or stalled run.
